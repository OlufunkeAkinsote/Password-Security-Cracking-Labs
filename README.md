# Password-Security-Cracking-Labs
This project focused on practical password-security testing within an authorized laboratory environment.  I explored password hashes, protected PDF files, password recovery techniques, security tools, and the importance of properly documenting technical evidence during a cybersecurity assessment.

Another week, another opportunity to learn, practice, and grow! 

This week’s project focused on practical **password-security testing** within an authorized laboratory environment.

I explored password hashes, protected PDF files, password recovery techniques, security tools, and the importance of properly documenting technical evidence during a cybersecurity assessment.

### 🛠️ Tools Used

• Windows
• John the Ripper (JTR)
• Johnny GUI
• NetworkWalks Hash Calculator
• NetworkWalks Password Cracker
• Web Browser

### Key Activities

🔹 **PDF Hash Extraction**
Extracted the password hash from an authorized protected PDF for controlled laboratory testing.

🔹 **John the Ripper & Johnny GUI**
Configured Johnny, loaded the extracted hash, initiated the password-recovery process, and verified the result.

🔹 **NetworkWalks Security Tools**
Used the NetworkWalks Hash Calculator to obtain the PDF hash and the Password Cracker to perform the password-recovery exercise.

🔹 **Password Verification**
Verified the recovery result by successfully opening the protected PDF.

🔹 **Evidence Documentation**
Captured and organized screenshots throughout the process to document the technical workflow and results.

### Key Takeaways

This project helped me understand:

✅ How password hashes are used during authorized security assessments
✅ Practical use of **John the Ripper and Johnny GUI**
✅ Password-recovery workflows and security tools
✅ How password complexity can influence password-recovery difficulty
✅ The importance of strong password practices
✅ Proper collection and documentation of technical evidence

### Key Learning Outcome

This project strengthened my practical understanding of **password security, hash analysis, protected-file security, password-recovery methodologies, John the Ripper, security tooling, evidence collection, and professional cybersecurity documentation.**

One thing I continue to appreciate throughout this internship is the opportunity to move beyond theory and actually **practice what I’m learning in a controlled environment.** Every lab gives me a better understanding of how security concepts work in the real world and how attackers may approach weaknesses that defenders need to protect against.
